necesitas crear una carpeta llamada
"sin_procesar" sin las comillas y dentro de esta carpeta
colocar las las facturas sin procesar...

El formato de estas facturas tiene que ser estrictamente el que
descargas de la SAT, ya que sin otro formato no funcionara

Almacena todas las facturas en la carpeta antes mencionadas y luego
corre el Script, este sera capaza de leer los documentos y extraer

*Tipo de Factura
*proveedor
*Nit emisor
*serie
*Numero de DTE
*Descripcion
\*Total de Factura

no extrae precios individuales de cada articulo.

Posterior a ello lo almacena en un archivo xls o xlsx para que puedas procesarlo como
mejor te convenga.
